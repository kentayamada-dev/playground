---
name: block-gh-compound-command
enabled: true
event: bash
action: block
conditions:
  - field: command
    operator: regex_match
    pattern: (?:^|[;&|(\n`])\s*gh\s
  - field: command
    operator: regex_match
    pattern: \$\(|`|^(?!\s*gh\s)|^(?:[^'"\\]|\\[\s\S]|'[^']*'|"(?:[^"\\]|\\[\s\S])*")*?(?:(?:&&|\|\||;|\n)(?!\s*(?:gh\s|$))|(?<!\|)\|(?!\|)|(?<!&)&(?!&)|[<>])
---

`gh` をほかのコマンドと連結しているか、`$(...)`・バッククォート・リダイレクトを使っています。

この形はサンドボックスの `excludedCommands`（`gh *`）に一致せず、サンドボックス内で `~/.config/gh` を読めずに失敗します。サンドボックス外での再実行も deny で禁止しています（CLAUDE.md「gh と git push の実行」）。

`gh` を単独のコマンドにして書き直してください。

- JSON の一部を取り出す: `| jq` ではなく `--jq` を使う
- 複数行の本文を渡す: `$(cat <<'EOF' ...)` ではなく、本文をファイルに書いて `--body-file <ファイル>` で渡す
- 別のリポジトリを操作する: `cd` ではなく `-R owner/repo` を使う
- 出力をほかのコマンドで加工する: `gh` だけを実行し、出力を読んでから次のコマンドを別に実行する

検出条件: `gh` の呼び出しを含み、次のどれかに当てはまるコマンド。`gh` 同士を `&&`・`||`・`;`・改行でつないだものは検出しません。

- `gh` 以外で始まる
- `$(`・バッククォートを含む（クォートのなかも含む）
- クォートの外に `|`・`&`・`;`・`<`・`>`・改行がある
